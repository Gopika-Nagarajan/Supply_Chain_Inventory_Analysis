# Supply Chain & Inventory Analysis Dashboard

## Project Overview
This project focuses on analyzing supply chain and inventory data using Microsoft Excel. It provides insights into inventory performance and helps present important business metrics through a dashboard.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

## Project Objectives
- Analyze supply chain and inventory data.
- Monitor inventory performance.
- Identify important inventory trends.
- Present insights through an Excel dashboard.

## Key Features
- Inventory data analysis
- KPI calculations
- Pivot Table analysis
- Charts and visualizations
- Dashboard reporting
